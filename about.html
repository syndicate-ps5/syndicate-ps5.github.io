Die SYNDICATE Research Division führt die öffentliche Forschung und Dokumentation des Projekts SYNDICATE.The SYNDICATE Research Division carries the public research and documentation of the SYNDICATE project.

Leitsatz: Understand. Research. Develop. Document.Motto: Understand. Research. Develop. Document.

AbgrenzungSeparation

Öffentliche Forschung und interne Entwicklung werden getrennt verwaltet. Dieses Repository der Website und das öffentliche Forschungsrepository enthalten nur freigegebene öffentliche Inhalte.Public research and internal development are managed separately. This website repository and the public research repository contain only approved public material.

VeröffentlichungsregelPublication rule

Forschungsergebnisse werden erst nach Quellenprüfung, Bewertung der Beleglage und Freigabe veröffentlicht. Eine umgesetzte Notiz ist dadurch nicht automatisch verifiziert.Research results are published only after a source check, an evidence assessment, and approval. An implemented note is not automatically verified.

Was diese Website nicht istWhat this website is not

Sie ist keine Produktseite, enthält keine Downloads und kündigt keine verfügbaren Konsolenfunktionen an. Geplante Arbeit bleibt als geplant gekennzeichnet.It is not a product page, it contains no downloads, and it does not announce console features as available. Planned work stays marked as planned.
